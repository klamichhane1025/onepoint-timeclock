# OnePoint Time Clock

Interactive frontend mock for the OnePoint Time Clock product.

## Current phase

- Mock data only
- No Supabase connection yet
- No production authentication yet
- Intended for UI/UX review before backend integration

## Included mock flows

- Owner dashboard overview
- Timesheets & Payroll
- Exact date/time filters
- All Employees default filter
- Double-click time editing
- CSV export
- Multi-store payroll views
- Optional hourly/monthly job codes
- Employee creation
- Store onboarding beyond four locations on Free
- Employee kiosk clock-in/clock-out
- Admin Free/Paid plan assignment mock
- Audit trail mock
